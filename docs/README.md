# Documentación de NEXUS

Esta carpeta describe la entrega H3 y una evolución propuesta. Los formularios WinForms y la persistencia SQL Server son diseños futuros; la aplicación del repositorio todavía es de consola .NET Framework 4.8.

- [Diseño del juego](diseno-del-juego.md): visión, reglas, ciclo de juego, alcance y navegación.
- [Arquitectura actual](arquitectura-actual.md): diagnóstico del código H3.
- [Arquitectura propuesta](arquitectura-propuesta.md): capas de presentación, aplicación, dominio y datos.
- [Modelo de datos propuesto](modelo-de-datos-propuesto.md): entidades y estrategia de guardado/carga SQL Server.
- [Análisis técnico](analisis-tecnico.md): alternativas, decisiones, riesgos y fuentes oficiales.
- [Wireframes y navegación](evidencias/bocetos.md): menú, exploración/mapa, misiones e inventario.
- [Diagramas](evidencias/diagramas.mmd): secuencia, arquitectura y modelo relacional.

Las observaciones de H3 se basan en `Program.cs`, `nexus 2.0.csproj`, `nexus 2.0.sln` y `App.config`. Los elementos identificados como propuestos no deben considerarse implementados.
